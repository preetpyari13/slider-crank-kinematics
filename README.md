# Slider-Crank Mechanism: Velocity and Acceleration Analysis

Course project (Theory of Machines, SVNIT Surat) under Dr. Vimal K. Patel.

## Problem
A six-link mechanism with crank OA (50 mm) rotating at 200 rpm counter-clockwise. Find:
- Velocity of slider S and angular velocity of link QB
- Acceleration of slider S and angular acceleration of link QB

## Dimensions
OA = 50 mm, AS = 200 mm, BS = 50 mm, BQ = 100 mm.

## Method
Scaled velocity and acceleration diagrams, with centripetal and tangential acceleration components calculated for each link.

## Results
| Quantity | Value |
|---|---|
| Slider velocity | 0.953 m/s |
| Angular velocity of QB | 9.74 rad/s |
| Slider acceleration | 17.54 m/s² |
| Angular acceleration of QB | 140.35 rad/s² |
